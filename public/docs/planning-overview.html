潮待熟成 中島
NAKAJIMA TIDE CUT

千葉発・「潮のリズム」で肉と出会う、これまでにない精肉店

コンセプト（一言）

東京湾の潮位と月齢を「味のカレンダー」にした熟成肉専門店。 千葉の浜風と湿気を活かした独自熟成を行い、「今日の潮」に合う部位だけを一枚ずつ切り出して届ける。 肉屋であり、湾岸の灯台守が残すような「切り口の記録」でもある。

千葉出身・中島 潮位連動メニュー 湾岸熟成 一枚切り出し

なぜ「今までにない」のか

  • おすすめ部位が日替わり固定メニューではなく、実際の潮位・月齢ロジックで変わる（サイト上で「今日の潮カード」を表示）。
  • 熟成環境を「千葉の海側の湿気」をストーリーと体験設計に組み込み、産地＋気候＋時間を一本の軸にする。
  • 購入前は申込・問い合わせで「欲しい切り口・人数・調理法」を伝え、店側が潮カレンダーに沿って提案する（EC一括陳列型ではない）。

ターゲット

都心・千葉・茨城など湾岸圏で、スーパーの均一な肉ではなく「理由のある一枚」を食べたい人。 焼肉・ステーキ・鍋を自宅で楽しむ層、贈答、記念日の食事を作る人。

提供価値

味 短熟成〜長熟成を部位ごとに設計。潮の「満ち引き」に合わせ fat の融点・旨味の出方が変わる部位を選ぶ。
体験 各商品に「潮位メモ」「切り方」「火入れ一枚絵」を付属。肉を買うより切り口を受け取る感覚。
信頼 千葉県出身の店主・中島が顔と名前で担保。匿名のブランド量産店との差別化。

店舗・ブランドのトーン

  • ビジュアル：深い海色 × 砂浜のベージュ × 珊瑚のアクセント（灯台・潮表のモチーフ）。
  • コピー：短く、詩的すぎず、職人の断言。「今日は満潮寄り。肩ロースではなく、板腱を切る。」
  • 音・空間（将来）：潮の音を低音量で流すカウンター、熟成庫を見える化。

Web サイト（今回のスコープ）

  • 技術：Next.js（App Router）、TypeScript、Tailwind CSS。
  • 公開：GitHub でソース管理 → Vercel で本番公開。
  • 申込フォーム：名前・連絡先・希望内容を送信 → Resend で申込者へ「お問い合わせありがとうございます」自動返信（送信元：rsensui@tekion.jp、要 Resend ドメイン設定）。
  • 主要ページ：トップ（コンセプト・今日の潮カード）、コンセプト詳細、申込、フッター（店舗準備中の旨）。

当面のフェーズ（ロードマップ）

Phase 1 Web 公開・事前申込受付（現在）。実店舗オープン前のファン・試食希望者を集める。
Phase 2 ポップアップ／千葉湾岸での試食イベント。「潮カード」と実際の味の一致を検証。
Phase 3 実店舗＋定期便（満ち日・引き日セット）。

オーナー

中島（千葉県出身）— 精肉の仕入れ・熟成・一枚切りを一手に担う。 「千葉の海側で育った舌で、湾のリズムに合わせた肉だけを切る」を掲げる。
